# 命令手册

所有命令都在**源码仓库根目录**下跑；本技能的 `scripts/nb.py` 会自动切过去，等价写法：
`python scripts/nb.py <子命令> ...` == `cd <root> && python cli.py <子命令> ...`

## 一、离线（不用开达芬奇）

### inspect —— 只看结构，不写文件
```bash
python scripts/nb.py inspect -i "<草稿目录>"
```
打印轨数/片段数/总长/帧率推断结果/警告。**动手前先跑它**，确认帧率和轨序。

### convert —— 出交换文件
```bash
python scripts/nb.py convert -i "<草稿目录>" -t resolve -o <输出目录> --plan   # ① 出确认单，不写文件
python scripts/nb.py convert -i "<草稿目录>" -t resolve -o <输出目录> --yes    # ② 用户确认过，真转
python scripts/nb.py convert -i "<草稿目录>" -t resolve -o <输出目录> --yes --import   # ③ 转完直接导入并打开
```
| 参数 | 何时动 |
|---|---|
| `-t resolve\|pr\|jianying\|drt` | 目标端；达芬奇用 `resolve`（FCPXML），原生工程用 `drt` |
| `-o` | 输出目录（默认 `out`，会往里写 fcpxml + 报告 + `_media_relink/`） |
| `--plan` | 只打印**转换前确认单**（帧率来源/工程尺寸/时长/轨数/输出路径/待拍板项），不写任何文件 |
| `--yes` | 已跟用户确认过帧率与尺寸。**不加且非交互 → 打确认单后退出码 3，什么都不写** |
| `--size 1920x1080` | 目标工程尺寸，也认 `4K`/`1080p`。与草稿画布不同时按新画布重算位移与缩放 |
| `--import` | 转完自动导入达芬奇：备份旧时间线(.drt) → 删同名 → 导入 → 打开 → 核对帧数/轨数（仅 `-t resolve`） |
| `--keep-old` | `--import` 时不删同名旧时间线；导入会变成 `名字 1`，一般不该用 |
| `--fps 30` | 草稿没写帧率时默认按片段边界推断；报告里对齐率低才手动指定 |
| `--orig-audio track\|video\|off` | 视频轨自带原声：`track`=单列"Vn 原声"轨（默认）；`video`=挂视频上；`off`=丢 |
| `--keep-watermark` | 只有真要保留剪映推广水印时才加 |
| `--keep-jy-dup` | 默认会删掉剪映音轨里"被完全包住"的同源重复；要原样保留时加 |
| `--still-anchor center` | 静帧位置基准；达芬奇实测按底边对齐，默认已补偿 |
| `--scale-mode native` | 项目里关掉了 Image Scaling 才用 |
| `--y-down` | 画面整体上下镜像时才用 |

`--import` 的失败顺序是安全的：**备份失败就不删**；删了之后导入失败会**自动从备份导回**，救不回来会把备份路径打出来。备份文件落在输出目录，叫 `_backup_<时间线名>_<时间戳>.drt`，不当产物处理，确认无误后可删。

### audit_export.py —— 导入前的硬门禁
```bash
python tools/audit_export.py --fcpxml <导出.fcpxml> --draft "<草稿目录>"
python tools/audit_export.py --verbose      # 连 1x 段一起列
python tools/audit_export.py --json         # 机器可读
python tools/audit_export.py --strict       # 缺段/多余段也算失败
```
判据：`predict_in = 导出 start × speed`，与草稿 `source_timerange.start` 比。
`--draft` 现在直接吃**加密草稿目录**（内部解密），不用手工导出明文。
退出码 **0 才能进下一步**。

输出里这两行是正常的，不是错误：
```
已解释: 草稿自身重复 2 项(去重已吸收)、默认剔除水印层 1 项
```

## 二、在线（达芬奇必须开着）

前提：`首选项 > 系统 > 常规 > 外部脚本使用 = 本地`，改完**重启达芬奇**。

### post —— 转场 + 淡变 + 蒙版，一条命令做完（推荐入口）
```bash
python scripts/nb.py post -i "<草稿目录>" --audit   # 离线：只数数量，不用开达芬奇
python scripts/nb.py post -i "<草稿目录>"           # 在线预演：逐条对账，不写入
python scripts/nb.py post -i "<草稿目录>" --go      # 写入并保存
```
固定顺序 **转场 → 淡变 → 蒙版**，理由是顺序本身会影响结果：

| 顺序 | 为什么 |
|---|---|
| 转场先 | 真实转场优先占位；淡变的画面渐显也是 `Cross Dissolve`，它会读已有转场集合避让。反过来先跑淡变，该上 BCC+ 的切点会被普通叠化占掉 |
| 淡变其次 | 声音走 `SetFades`，画面走 `Cross Dissolve` |
| 蒙版最后 | 它建 Fusion comp，前两步都是非破坏性转场操作，互不影响 |
| `--fix-shell` 最前 | 它删段重放，会把已挂的转场和 comp 一起丢掉 |

参数：
- `--only trans,fades,masks` —— 只跑其中几步，顺序仍按上表
- `--allow-bottom` —— 蒙版忠实模式（最底层也套，默认跳过）
- `--fix-shell` —— 开头先清历史空壳（会删段重放）
- `--fps` —— 草稿帧率，默认自动推断（与 `convert` 一致）
- `--ignore-tl-mismatch` —— 跳过时间线校验（确认就是这条、但帧数差得多时用）

落位校验（默认开启，别关）：开跑前比对当前激活时间线的帧数与草稿总帧，差 0.5% 以内才放行。
对不上会把工程里所有时间线连帧数列出来、标出帧数对得上的那条，`--go` 直接中止、一个字都不写。
没有这一步时，激活到只含部分段落的试验版会让所有效果按帧号落到错误位置，而每一步都返回成功。

`--audit` 完全不连达芬奇，只读草稿算数量，适合导入前确认"草稿里到底有没有这些效果"。
`--go` 全部成功才返回 0；任一步失败返回 1，但**不会回滚**已写入的部分 —— 修完再跑一次即可，
转场/蒙版都有防重复（已有转场跳过、同一段不重复建 comp）。

### audit_inpoint.py —— 导入后第一件事
```bash
python tools/audit_inpoint.py -i "<草稿目录>" [--tol 3]
```
逐段比 `GetSourceStartFrame()` 与草稿源入点（按**素材池真实 FPS** 换算）。
自动跳过 `Fusion Clip`（源入点不可读）。退出码 0 = 无异常。

### fades —— 补声音淡变 + 画面交叉叠化
```bash
python scripts/nb.py fades -i "<草稿目录>" --audit    # 只读对账
python scripts/nb.py fades -i "<草稿目录>"            # 写入 + 逐条读回
```
视频的 `SetFades` **不持久化**，所以画面渐显/渐隐一律用 Cross Dissolve 转场。
头部已有叠化的段会跳过，避免双重渐显。

### trans —— 剪映转场写进时间线（含 BCC+ 平替）

```bash
python scripts/nb.py trans -i "<草稿目录>" --audit   # 离线：只列计划（自动推断草稿帧率）
python scripts/nb.py trans -i "<草稿目录>"           # 在线：定位宿主 + 报对齐策略（不写）
python scripts/nb.py trans -i "<草稿目录>" --go      # 写入并保存
```

剪映把转场挂在**宿主片段尾部**，位置 = `target_timerange.start + duration`（不是起点，坑 31）。
默认对齐 `center`；入口段 `source.start == 0`（含静帧）时自动退 `left`，否则 `AddTransition`
静默返回 `None`（坑 33）。

映射表在 `nlebridge/transsync.py` 的 `TRANSITION_MAP`，每个剪映名是一串候选，前者失败依次后退：

| 剪映 | 达芬奇 | category |
|---|---|---|
| 叠化 | `Cross Dissolve` | simple |
| 闪白 | `Brightness Flash` | fusion |
| 闪黑 | `Inverse Flash` | fusion |
| 推镜变焦 | `BCC+交叉变焦溶解` | ofx |
| 放射 | `BCC+光线溶解` | ofx |
| 炫光 III | `BCC+镜头光晕溶解` | ofx |

BCC+ 用的是**界面显示名**：中文达芬奇填中文，英文界面走候选里的英文名。全失败进人工清单，
通常是插件没装或授权不覆盖 BCC+（预览带水印）。同一宿主已有转场会跳过；同帧同时长命中
多条轨也跳过（人工指定后再跑）。

### mask_report.py —— 套蒙版前先看清单
```bash
python tools/mask_report.py -i "<草稿目录>"
python tools/mask_report.py -i "<草稿目录>" --json
```
离线，不需要达芬奇。列出每个「挂了蒙版」的段：帧位、时长、轨、蒙版类型、`enable_video_mask` / `enable_adjust_mask`、下方重叠层、AI 抠像有效帧占比，以及**判定与理由**。

用途：草稿**没有**「蒙版是否启用」的字段，只能靠三类间接证据判。这张表把证据摆出来，避免盲套。判定规则见坑位库 17 / 17b / 18。

### masks —— 补蒙版/文字/AI 抠像链
```bash
python scripts/nb.py masks -i "<草稿目录>" --audit          # 只读对账
python scripts/nb.py masks -i "<草稿目录>"                   # 写入
python scripts/nb.py masks -i "<草稿目录>" --allow-bottom    # 忠实模式：底层也照草稿套
```
写之前先跑 `mask_report.py`。默认三类跳过：最底层段、调节蒙版段（`enable_adjust_mask=False`）、`enable_video_mask=False` 的段。

跳过统计会打印在计划后面；**被跳过的段不会创建 comp**，所以新转出的时间线没有空壳。
`--allow-bottom` 只在用户明确要求"角色浮在纯黑上也照套"时用，别自己加。

文字用 No-Ripple 配方：`AddTrack("video")` → 临时片段 → `CreateFusionClip` → 写 TEXT_LUA。
发光参数以用户手改值为准，别覆盖。

### fix-shell —— 清掉草稿里不需要的空壳 comp
```bash
python scripts/nb.py fix-shell -i "<草稿目录>"              # 预演，只读
python scripts/nb.py fix-shell -i "<草稿目录>" --go         # 执行
python scripts/nb.py fix-shell -i "<草稿目录>" --go --only 642   # 只修某一段
python scripts/nb.py fix-shell -i "<草稿目录>" --go --enable     # 顺带恢复被禁用的段
```

comp 删不掉（坑 20），只能"删片段 → 按草稿重放 → 回填属性"，所以这一步会真的动时间线，务必先看预演。

**空壳判定**三条件全中才算：① 草稿里有轨+帧+时长完全对得上的素材段 ② 媒体池项 `File Path` 非空 ③ 不在蒙版计划里。
文字层、`NBMatteLoad` 之类的复合片段因 `File Path` 为空自动保留（坑 28）。

重建时会继承原片段的 `ZoomX/ZoomY/Pan/Tilt/Rotation/...`、淡变、名字、标记色、启用状态；
**有调色节点（`GetNumNodes() > 1`）的段默认拒绝**，要动得加 `--force`（会丢调色）。

帧号要折算素材帧率（坑 29）：`src_in = floor(草稿src_in × src_fps/tl_fps)`。
验收看源区间是否与相邻段首尾相接，别只看时长。

### fix_inpoint.py —— 只用于历史时间线
```bash
python tools/fix_inpoint.py -i "<草稿目录>"          # 预演
python tools/fix_inpoint.py -i "<草稿目录>" --go     # 执行
```
新转换的时间线不需要它（写入器已根治）。

### doctor —— 核对达芬奇工程库里的实际结构
```bash
python scripts/nb.py doctor -p "<工程名>" [-i "<草稿目录>"]
```

## 三、退出码约定

| 码 | 含义 |
|---|---|
| 0 | 全绿 |
| 1 | 有需修项（入点/速度/边界）；`--import` 失败也返回 1 |
| 2 | 前置不满足（连不上达芬奇、时间线不对、`--import` 配了非 resolve 目标） |
| 3 | **转换前还没确认**（非交互下没给 `--yes`）：确认单已打印，可以去问用户了；不是故障 |
